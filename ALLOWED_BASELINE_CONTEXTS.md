# Brand independence and baseline-use boundary

Verification date: 2026-06-07

This is an independent local research track. Third-party repositories and paper names may appear ONLY in provenance, citation, benchmark, and adapter documentation. They must not be used as local package names, API names, figure branding, or manuscript claims.

Allowed uses: (1) cite the reference paper; (2) run the frozen baseline for parity/ablation; (3) thin adapters explicitly named as baseline adapters; (4) compare metrics/runtime/inputs/outputs under reproducible conditions.

Forbidden until a separate license/design review passes: (1) copying upstream source into local `src/`; (2) reusing upstream class/function names as project branding; (3) restating upstream abstracts/captions/claims as local novelty; (4) implying biological/clinical performance before local evidence; (5) mixing article and software licenses.

Local contribution language must emphasize the refinement in README + CLAIM_LEDGER, not the baseline name. NOTE: any historically-banned brand (INSPIRE/HarveST/CellNiche/scComm/stPainter/DeepSpatial) may appear ONLY here/in manifests, never in executable source — the parent scripts/leakage_scan.py gate enforces this.
